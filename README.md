## ✨ 核心特色與架構優勢

* 🔒 **100% 離線純本機運行**：無後端伺服器資料庫、無任何遙測紀錄。所有資料均以 AES-256 加密存在瀏覽器本地持久儲存區。
* 🔑 **高規格密碼學防護**：基於 300,000 次 PBKDF2（高迭代雜湊）+ AES-GCM 256 位元對稱加密，符合最新 OWASP 抗暴力破解標準。
* 🧹 **記憶體與剪貼簿防殘留防護**：鎖定或閒置超時自動觸發 RAM Scrubbing 徹底清空解密資料物件，並即時抹除剪貼簿中的明文密碼。
* 📱 **近場光學動態 QR 離線傳輸**：更換新手機或跨裝置轉移資料時，免連 Wi-Fi、免配對藍牙，直接使用相機對準動態 QR Code 掃描，純光學完成加密同步。
* 👆 **生物辨識快速開鎖**：支援系統原生 WebAuthn（Apple Face ID / Touch ID、Android 指紋辨識、Windows Hello），秒開保險庫。
* 🆘 **Email 離線救援憑證**：內建 16 碼緊急金鑰離線救援機制，零知識架構下本機絕不儲存明文金鑰，救援解鎖並重設密碼時保證資料 100% 完整無損還原。
* 📊 **UTF-8 BOM CSV 匯出與脫敏模式**：支援完整備份或脫敏防窺模式匯出，相容 Windows / Mac Excel 繁體中文，內建深度防公式注入保護。

## 📲 跨平台安裝指南 (PWA)

SafeVault 符合完整 Progressive Web App (PWA) 規範，透過瀏覽器即可一鍵安裝為獨立應用，**安裝後即使關閉 Wi-Fi 或處於飛航模式也能秒速開起！**

### 📱 Android 手機 / 平板（Chrome / Edge / 三星瀏覽器）
1. 使用瀏覽器開啟部署完成的網址。
2. 畫面底部會自動浮現 **「新增 SafeVault 至主螢幕」**，或點選瀏覽器右上角選單（`⋮`）➔ 選擇 **「安裝應用程式」** 或 **「新增至主螢幕」**。
3. 完成後即可在手機桌面找到 **SafeVault** 圖示，享受全螢幕獨立運行體驗（無頂部網址列干擾）。

### 🍏 iPhone / iPad（Safari 瀏覽器）
1. 在 iOS 系統中請使用 **Safari** 開啟網址。
2. 點擊螢幕底部工具列中央的 **「分享」按鈕**（方框帶向上箭頭 ⎋）。
3. 向下滑動找到並點擊 **「加入主畫面 (Add to Home Screen)」**。
4. 點選右上角「新增」，即可在 iOS 桌面生成 App 圖示。

### 💻 電腦版（Google Chrome / Microsoft Edge / macOS Safari）
1. 使用 Chrome 或 Edge 開啟網址。
2. 網址列最右側會出現 **「安裝 SafeVault」** 圖示（或在右上選單選擇「安裝 SafeVault」）。
3. 安裝後即可常駐於 Windows 開始功能表、工作列或 macOS 應用程式資料夾中，點擊獨立視窗啟動。

## 🚀 快速上手：初次初始化與安全設定

當您第一次開啟 SafeVault 時，系統會引導您建立最高防護的主密碼：

1. **設定主密碼 (Master Password)**：
   * 請輸入一組高強度的記憶主密碼（建議 8 位以上，包含大小寫字母、數字與符號）。
   * 此密碼是推導 AES-256 加密金鑰的唯一依據，**請務必牢記**！
2. **啟用生物辨識解鎖（選用，強烈推薦）**：
   * 進入「設定」開啟「生物辨識解鎖」，即可綁定手機指紋或 Face ID，每次開啟保險庫點擊即可秒解鎖。
3. **綁定 Email 離線緊急救援憑證**：
   * 在「設定」填入您的信箱並生成專屬 **16 碼緊急救援金鑰**。
   * 請將此金鑰複製備存至離線筆記本；日後若不慎忘記主密碼，憑信箱與此 16 碼金鑰即可在本地安全重設密碼。

## 📖 完整功能使用說明

### 1. 保險庫帳密管理（樹狀階層與明細）
* **樹枝階層目錄（保險庫 ➔ 全部）**：
  * 所有資料以 **「分類資料夾 ➔ 單元名稱」** 樹枝引導線呈現，告別傳統瀑布流佔版面問題。
  * **預設全部收合**：進入「全部」目錄預設整齊收合，點擊特定分類資料夾展開，點選單元名稱即流暢展開詳細帳密明細。
  * **全局展開/收合**：頂部提供【全部展開】與【全部收合】雙向快捷鍵，支援單手一鍵統整。
* **新增與編輯帳密**：
  * **智慧分類標籤**：點擊新增時，系統提供 12 大熱門分類標籤（網銀金融、社群通訊、商務工作、購物等），並動態聚合您歷史建立過的所有自訂分類，隨點即套用。
  * **分類智慧繼承**：在特定分類（例如「網銀金融」）點擊「新增」，編輯器自動預填該分類。
  * **自訂欄位系統**：每個單元除帳號、密碼外，可無限增加自訂標籤欄位（如：統一編號、信用卡到期日、備援電話）。
  * **敏感隱私欄位開關**：自訂欄位可設為「敏感遮罩」（如 CVV、交易密碼），在明細中預設以 `••••••••` 防身後偷窺，點擊眼睛圖示方可解除遮罩。
* **安全複製與自動清空剪貼簿**：
  * 點擊帳號或密碼旁的「複製」鈕即可秒速複製，並觸發安全的智慧倒數計時清空防護（預設 30 秒自動清空剪貼簿內容）。

### 2. 範本庫管理（9 大生活範本與自訂）
* **預置 9 大標準範本**：
  * 涵蓋：網路銀行、信用卡、行動 App、廠商採購平台、電子郵件、伺服器主機、社群平台、Wi-Fi 路由器、身分證件等格式。
* **單元一鍵轉為新範本**：
  * 在任何自訂帳密單元中，點擊「轉為範本」，即可將該單元的欄位結構一鍵儲存為全新範本。
* **樹枝層級目錄**：
  * 範本庫全面對齊樹枝結構，支援單元點擊展開預覽欄位架構，並附帶一鍵「套用此範本建立新帳密」。

### 3. 常用個人資料庫（敏感遮罩與標籤聚合）
* **常用資料快速取用 (Identity Snippets)**：
  * 集中保管各類常用繁複字串：戶籍地址、收件地址、手機號碼、身分證號、統一編號、護照號碼、銀行轉帳帳號等。
* **敏感資料遮罩保護 (`isSensitive`)**：
  * 機敏字串（身分證字號、門禁密碼、卡號）可開啟「敏感資料遮罩」，列表預設以星號隱蔽防窺，右側附帶專屬小眼睛圖示隨時點擊檢視。
  * 點擊複製不受影響，即使在隱蔽狀態下仍可直接複製真實文字至剪貼簿。
* **自訂標籤即時回顯分類區**：
  * 任何自訂的分類標籤儲存後，立即動態回顯於編輯視窗頂部與首頁滑動分類標籤列中，點選即秒速過濾。
* **在帳密編輯器中快速調用**：
  * 編輯帳密單元時，點擊「調用常用資料」，一鍵將身分證或銀行帳號匯入為自訂欄位，並自動繼承敏感遮罩設定。

### 4. 強密碼產生器（熵值評估與自選組合）
* **獨立密碼產生器視窗**：隨時點擊頂部或底部的鑰匙圖示即可叫出。
* **彈性長度與字元組合**：
  * 長度滑桿自由調節（8 ~ 64 位元）。
  * 自由勾選大寫字母 (A-Z)、小寫字母 (a-z)、數字 (0-9)、特殊符號 (!@#$%^&*)。
  * **排除易混淆字元**：可開啟過濾 `1`, `l`, `I`, `0`, `O` 等肉眼難以辨識的字元。
* **密碼強度即時評分與熵值檢驗**：依據密碼資訊熵即時分析安全等級（極弱 ➔ 弱 ➔ 中等 ➔ 強 ➔ 軍規極強）。

### 5. 編輯防呆：n 步歷史復原、刪除提醒與回收站
* **編輯器內建 n 步回復 (Undo) 與重作 (Redo)**：
  * 編輯帳密時支援高達 50 步操作歷史軌跡，提供頂部【↩ 回復】、【↪ 重作】按鈕，並全面支援鍵盤快速鍵（`Ctrl+Z` / `Cmd+Z`、`Ctrl+Y` / `Cmd+Shift+Z`）。
  * 支援【還原至開啟前狀態】，誤改、誤刪欄位一秒復原。
  * 編輯未儲存防誤觸警示：點擊背景遮罩時自動提醒，防止意外遺失輸入中的內容。
* **單元刪除專屬安全提醒**：
  * 淘汰生硬的瀏覽器彈窗，全面採用防手滑精緻確認視窗，清晰列出即將刪除之單元名稱、帳號與欄位資訊。
* **8 秒底部即時救回 Toast (Instant Undo)**：
  * 單元被刪除時，畫面底部懸浮 8 秒互動提示，點擊【↩ 立即救回】立即取消刪除。
* **最近刪除回收站（Trash Bin）**：
  * 所有刪除項目皆以 AES-256 加密存入「最近刪除回收站」。
  * 隨時可點開回收站檢視被刪除單元的帳號與密碼，並支援個別單元一鍵復原或全部清空。

### 6. 近場光學無網跨裝置同步（動態 QR Code）
* **安全原理**：
  * 兩台裝置之間**完全不需要連上相同的 Wi-Fi，也不需要藍牙配對**。
  * 發送端將選取的資料經過暫時性 6 位數 PIN 碼加密後，轉換為高密度或多影格動態二維碼；接收端透過手機鏡頭即時掃描光學訊號、輸入同組 PIN 碼即可在本地端解密寫入。
* **發送端操作**：
  1. 點擊頂部「同步」按鈕 ➔ 勾選欲同步的單元（支援單筆、多選或全選）。
  2. 設定或隨機產生一組 6 位數傳輸 PIN 碼。
  3. 畫面即刻生成高密度 QR Code（資料量較大時會自動以 550ms 間隔循環輪播動態影格）。
  4. 支援【全螢幕 520px 超大二維碼放大】：30~50cm 遠距也能輕鬆秒讀，防止近拍手震與反光。
* **接收端操作**：
  1. 點擊「接收同步」➔ 輸入相同的 6 位數 PIN 碼。
  2. 鏡頭對準發送端螢幕（相機取景框採 78% 黃金比例，支援 1x / 1.5x / 2x / 2.5x 變焦）。
  3. 掃描成功後自動嗶聲並閃爍綠光，進入「接收單元比對預覽」。
  4. 支援比對本地既有資料（新單元、有差異單元、完全一致單元），點擊【完成並寫入儲存】即 100% 安全入庫。

### 7. 匯出帳密備份（CSV 格式與 UTF-8 BOM 防亂碼）
* **路徑**：進入「設定」➔ 找到【匯出帳密備份 (CSV 試算表)】。
* **繁體中文 Excel 100% 防亂碼**：
  * 檔案頭自動寫入 UTF-8 Byte Order Mark (`\uFEFF`)，在 Microsoft Excel (Windows/Mac)、Google 試算表、Apple Numbers 開啟，繁體中文字元皆能正常呈現，徹底告別問號或亂碼。
* **標準規範與安全防護**：
  * 遵循 RFC 4180 標準處理逗號、引號與換行。
  * **深度試算表公式注入防禦 (Deep Formula Injection Protection)**：針對首字元為 `=`, `+`, `-`, `@`, `\t`, `\r`, `|`, `%` 的輸入欄位，自動加上前置安全跳脫，徹底防止試算表惡意執行巨集或跨軟體動態指令（DDE）。
* **脫敏防窺安全備份模式**：
  * 匯出時可勾選「以遮罩隱藏密碼與敏感資料（脫敏模式）」，所有密碼與自訂敏感欄位將以符號遮罩（例如 `••••••••••••`）替代，匯出後檔名自動標註 `_脫敏防窺`，適合用於帳號盤點、資產目錄歸檔或在非安全環境中備份帳號清單。
* **高敏明文風險警示確認窗**：
  * 彈出高辨識安全確認視窗，提醒使用者匯出的完整 CSV 檔案為未加密的明文，強烈建議存放於硬體加密隨身碟（BitLocker/FileVault）或冷儲存離線硬碟。
  * 自由勾選是否包含自訂屬性欄位，以及是否額外包含「最近刪除回收站」中的資料。
  * 自動生成標準帶時間戳之檔名（例如：`SafeVault_帳密備份_20261103_153000.csv`）。

### 8. 安全偏好中心（自動防窺鎖定、記憶體擦除與剪貼簿防護）
* **記憶體明文即時銷毀 (RAM Scrubbing on Lock)**：
  * 每次執行「手動鎖定」或「超時自動鎖定」時，系統會立即清空 React State 與全域暫存中的解密帳號密碼陣列，將記憶體結構歸零，防止裝置遭惡意軟體傾印記憶體（Memory Dump）提取敏感資訊。
* **即時清空剪貼簿防護 (Instant Clipboard Wipe)**：
  * 除了可設定 15 秒、30 秒、60 秒自動倒數清除剪貼簿外，當保險庫執行鎖定或切換視窗鎖定時，系統會**立刻強制清空系統剪貼簿**，不留任何安全暴露窗口。
* **自動超時防窺鎖定機制**：
  * 可自由設定：【切換視窗立即鎖定】、【閒置 1 分鐘】、【閒置 3 分鐘】、【閒置 5 分鐘】。
  * 逾時後記憶體加密金鑰立即銷毀並回到上鎖畫面；解鎖後會精準還原您剛才停留的工作畫面，無縫接續作業。
* **防暴力破解保護 (Anti-Brute-Force Rate Limiting)**：
  * 解鎖密碼比對失敗時加入平滑時間延遲防護，大幅增加自動化字典攻擊與暴力窮舉攻擊的運算時間成本。
* **300,000 次高強度 PBKDF2 金鑰衍生**：
  * 符合最新 OWASP 密碼學標準，並具備 100% 舊版相容性，既有保險庫無需重設即可平滑過渡。
* **變更主密碼 (Master Password)**：
  * 在設定中輸入新主密碼（強制驗證最小熵值），系統會重新生成隨機 Salt，並自動使用新金鑰將整個本地資料庫全面重新加密封裝。
* **危險區域：重設清空本地資料庫**：
  * 徹底銷毀本機儲存的所有加密資料庫，恢復出廠狀態。

### 9. 即時檢查更新與進版承諾
* **伺服器無快取真即時偵測**：
  * 點擊設定模組中的【檢查是否有更新】，系統會自動向伺服器端點以 `no-store` 發起查詢，精準比對版本號。
* **智慧更新按鍵判定**：
  * 當偵測到伺服器有新版本時，才會醒目顯示【發現新版待更新】並提供【立即更新至新版】按鍵；目前已是最新版本時，會友善提示並隱藏更新按鍵。
* **強制清除快取更新 (Hard Cache Busting)**：
  * 點擊立即更新時，智慧調用 Cache API 清除本機舊版前端快取，秒速加載最新程式碼。
* **進版安全承諾**：
  * SafeVault 的 AES-256 加密資料庫儲存於瀏覽器獨立存儲區，前端網頁的所有版本更新與快取替換，**100% 絕對不會影響、覆蓋或清除您已建立的任何帳號密碼、範本或自訂字串**！

## ❓ 常見問題與安全須知 (FAQ)

#### Q1: 如果我清除了瀏覽器的「瀏覽記錄與 Cookie」，我的資料會遺失嗎？
* **答**：一般清除「快取與瀏覽歷史」不會影響資料；但若您勾選了**「清除網站儲存空間 / 離線網站資料 (Storage & Cookies)」**，瀏覽器的本機資料庫可能會被重設。
* **安全建議**：
  1. 將 SafeVault **安裝為 PWA 獨立應用**（PWA 擁有獨立沙盒儲存區，受系統保護程度高於一般分頁）。
  2. 善用「設定」中的**【匯出帳密備份 (CSV)】**功能，定期將資料備份到離線加密隨身碟。
  3. 隨時可透過「近場 QR Code 同步」將資料備份到另一台手機或電腦。

#### Q2: 忘記主密碼怎麼辦？
* **答**：因為本系統採用真正的零知識本地加密，沒有任何後台管理員或伺服器可以幫您重設密碼。
* 若您在「設定」中曾綁定過 **救援 Email**，點選登入畫面的「忘記密碼？」，輸入您備存的 **16 碼緊急救援金鑰** 與信箱，即可在本地無損解鎖既有資料庫並重新設定新主密碼！

#### Q3: 換新手機時該如何轉移帳密？
* **答**：完全不需要將資料上傳到雲端！
  1. 新手機開啟 SafeVault 網頁並安裝為 App。
  2. 舊手機點選頂部「同步」➔ 全選所有資料 ➔ 設定 6 位數 PIN 碼並顯示動態 QR Code。
  3. 新手機點選「接收同步」➔ 輸入相同 6 位數 PIN 碼 ➔ 鏡頭對準舊手機掃描。
  4. 約 10 秒內即可透過光學傳輸完成全庫轉移！

#### Q4: 離線飛航模式下真的可以使用嗎？
* **答**：**是的，100% 保證可以！** SafeVault 的 Service Worker 會在您第一次連線加載完成後，將所有執行所需的程式碼與字型圖示完整快取至裝置端。關閉 Wi-Fi、行動網路或進入飛航模式，點擊圖示依然秒開且所有功能運作自如。

#### Q5: 在設定中綁定 Email 救援後，16 碼緊急金鑰會一直顯示嗎？
* **答**：**不會！** 這正是 SafeVault 遵循「零知識 (Zero-Knowledge)」與「最高防窺」原則的關鍵安全機制。16 碼金鑰僅於生成當下顯示一次供您抄存，當您確認備存並點擊【我已妥善記錄金鑰，隱藏並完成綁定】後，金鑰明文將自螢幕中永久隱藏，以防止旁人趁您解鎖手機時偷窺。本機僅儲存加密防篡改容器，日後憑您自行記錄的金鑰與信箱即可離線解密還原。

#### Q6: 在設定中變更主密碼後，Email 救援金鑰還能用嗎？
* **答**：**可以！** 自 v0.9.24 起，當您在「設定」變更主密碼時，系統會要求驗證當前主密碼，並於資料重新加密後**自動同步更新離線 Email 救援容器**，為您生成並展示全新的一組 16 碼緊急救援金鑰，徹底解決「主密碼變更後，救援容器仍殘留舊密碼致使解鎖失敗」之問題。

#### Q7: 為什麼授權驗證時不再出現瀏覽器預設的網域提示（例如「... 顯示」）？
* **答**：這是因為 SafeVault 全面淘汰了容易洩漏網站來源與無法防窺遮罩的瀏覽器原生 `window.prompt`，改以內建的純前端安全彈窗進行主密碼授權與輸入，支援密碼星號遮罩與防窺眼睛切換，不僅大幅提升隱私防護，更完全杜絕外露部署網域名稱。
